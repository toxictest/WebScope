# Synthetic / controlled-local examples

`complete-local/` is a complete-within-policy owned local HTTP fixture run. `controlled-local/` deliberately includes an oversized JavaScript response and therefore reports partial coverage. Both are generated by `WEBSCOPE_WRITE_SAMPLES=1 ./tests/run_tests.sh`.

They use reserved `.test` domains, fixture-only DNS answers and ephemeral loopback services. The ports will not be live after testing. They are not scans of a public organization or of the user's domain.

Open `report.html` for the summary/table, `report.json` for complete structured observations and policy/coverage information, or the individual URL/JS/directory lists. Sensitive candidates are not confirmed secret exposures. Query values and credential literals are redacted/omitted; no fixture private keys, cookies, raw TXT, complete page/JS bodies or actual credentials are included.

Vendor SurfaceIntel examples retain their own labels and validation context under `vendor/surfaceintel/examples/`.
