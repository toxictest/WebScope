# Changelog

## 1.0.0-rc2 — 2026-10-18

- Added no-write dependency checks/plans and explicit OS package installation for Debian/Ubuntu and Fedora/RHEL-family systems.
- Added runtime/development requirements files, machine-readable package lists, normal-user development venv instructions and setup regression tests.
- Refreshed release/schema tool version and generated examples; existing transport/discovery policy is unchanged.
- No packages installed, target scans run or scheduled jobs enabled during this setup update.

## 1.0.0-rc1 — 2026-10-18

Initial executable integrated linked-discovery release:

- Bash CLI launcher and Python standard-library orchestration with a bounded, persistent SurfaceIntel transport adapter.
- Explicit domain/tree/CNAME/CIDR/port/path authorization, DNS pinning, per-request revalidation, no inherited proxies or automatic redirect expansion.
- Root/imported/optional CT/linked hosts, robots and root sitemap discovery, HTML navigation and bounded JavaScript import/string/route parsing.
- Original ReconScope, URLMiner, HeaderGuard, DNSShield and TLSWatch local components, with explicit coverage differences from their standalone scanners.
- Metadata-only sensitive paths/source maps; no query values, secret values, raw page bodies or JS files in final reports; no credential validity checks.
- Private JSON/HTML/text reports, stable URL IDs, scope/CA digests, schema, overlap lock, interrupt cleanup, incomplete marker and explicit limits/partial coverage.
- Owned local HTTP/HTTPS/IPv6 tests and synthetic DNS/CT fixtures: 113 integration assertions passed; included SurfaceIntel backend: 206 assertions passed.

No existing tool source outside this new project was modified. No external crawler binaries, system installation, persistent jobs, public-target scans or GitHub publication were performed for this release. No full-browser, authenticated crawling, directory brute force, cloud object access or exhaustive-discovery claim is included.
